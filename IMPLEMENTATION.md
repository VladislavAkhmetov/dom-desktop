### Функциональные проверки перед выпуском

1. После паузы человек продолжает выбранное дело без поиска вкладок. Проверить на реальном рабочем дне; не подменять эту проверку демонстрационными данными.
2. Изменение проекта не требует повторного входа в те же рабочие аккаунты. До выпуска проверить модель браузерных профилей отдельно от модели пространств.
3. Незавершённая форма и активный звук переживают переход на главную и смену вкладки; очистка не закрывает их молча. Повторить на реальных сайтах после возврата к Electron.
4. ИИ использует только разрешённый контекст, подтверждаемые действия остаются конкретными, ошибка API не выглядит успешным завершением. Проверить на реальных провайдерах.
5. Почта показывает фрагменты честно, ошибка одного аккаунта не затрагивает другой, отзыв доступа предлагает понятное восстановление. Выполнить с OAuth-конфигурацией продукта.
6. Лишь после этих проверок возвращаться к Windows-дистрибутиву, подписи и проверке macOS.

### Пилот кабинетов — 7 октября 2026

Браузерный режим `?cabinet=1` проверяет пространство как самостоятельный рабочий кабинет без вложенного «Дела». Создание сразу открывает чистую вкладку; материалы и продолжение находятся рядом с браузером. Доступны первое имя по метаданным, ручное переименование, следующий шаг и заметка, ссылка на файл, общий материал в нескольких кабинетах, выделение выбранных вкладок, закрепление, архив и удаление с отменой.

Данные пилота изолированы: копия личного IndexedDB и отдельный demo sessionStorage. Старая библиотека сохраняется, неизвестные вкладки не отбрасываются, снимки не воскрешают закрытые страницы. Внутренний совместимый слой workContexts остаётся; в кабинете одна группа. Прежний режим работает без флага.

Уточнение навигации: выбор/создание/продолжение пространства из дашборда открывают материалы внутри его каркаса. На всю область приложения раскрывается только явно открытый браузер. Переключатель пространств браузера сохраняет браузерный режим, возврат сохраняет прежний раздел дашборда. Первое описание «создание сразу открывает чистую вкладку» относится к созданию из браузера.

Полная продуктовая сводка и границы следующей реализации: [docs/cabinet-upgrade.md](docs/cabinet-upgrade.md). Нативная выгрузка, наблюдение сторонних документов, локальный ИИ и планирование этим пилотом не реализуются. Сначала валидируем браузерный UX, затем Windows 11, после неё macOS.
