# Процедурный Calm Tech саунд-движок (Procedural Calm Sound Engine)

> **Назначение документа:** Техническая спецификация акустической концепции, синтеза и интеграции звукового оформления в `dombro`.

---

## 1. Акустическая концепция Calm Tech

В интерфейсах высокой концентрации стандартные цифровые «писки», высокочастотные клики и звонкие системные колокольчики разрушают спокойную атмосферу:
* Частоты выше **2500 Гц** подсознательно воспринимаются нервной системой как сигнал тревоги или предупреждения об ошибке.
*dombro* использует процедурный саунд-движок на базе **Web Audio API** без внешних аудиофайлов (0 МБ загрузки, мгновенная реакция без сетевых задержек).
* Все звуки синтезируются в реальном времени так, будто они записаны в тихой комнате с близкого микрофона — **глухо, матово и тактильно**.
* Верхние частоты срезаются Low-Pass фильтрами на уровне **1200–1800 Гц** (для щелчков дерева — 900 Гц, для выдоха — от 750 до 160 Гц).
* Каждый звук имеет случайное микро-отклонение высоты тона (**±3% Jitter**), благодаря чему слух не утомляется от монотонных повторений.

## 2. Архитектура и методы синтеза (`src/sound.ts`)

Движок реализован в виде синглтона `sound = new CalmSoundEngine()` с хранением пользовательской настройки в `localStorage ('dombro:sound-enabled')`.

### 1. Мягкий деревянный щелчок (`playWoodSnap(variant: 'hover' | 'land')`)
* **Физическая модель:** Глухой резонанс плотного дерева с мягким касанием фетра.
* **Синтез:**
  * Осциллятор с треугольной волной (`triangle`).
  * Частотная модуляция: экспоненциальный спад частоты от `baseFreq` до 58 Гц.
  * Low-Pass фильтр на 900 Гц.
  * Быстрая огибающая громкости (`exponentialRampToValueAtTime`) длительностью 25–45 мс.
* **Варианты:**
  * `'hover'` (наведение на ячейку / смена магнитного силуэта): `baseFreq ~ 260 Гц`, громкость `0.06`, длительность `0.025 с`.
  * `'land'` (посадка карточки в сетку): `baseFreq ~ 195 Гц`, громкость `0.18`, длительность `0.045 с`.

### 2. Шелест плотной бумаги (`playPaperFold()`)
* **Физическая модель:** Складывание нескольких страниц матового картона веером.
* **Синтез:**
  * Каскад из 3 микро-шорохов с временным сдвигом 0, 35 и 75 мс.
  * Генерация тёплого розового шума: рекурсивный фильтр `(lastOut + 0.08 * white) / 1.08`.
  * Полосовой Bandpass-фильтр в диапазоне 900–1500 Гц (`frequency = 1100 + index * 180`, `Q = 2.2`).
  * Мягкая огибающая затухания за 65 мс.

### 3. Тихий аналоговый тумблер (`playCaptureToggle(active: boolean)`)
* **Физическая модель:** Двухфазный мягкий переключатель push-to-talk.
* **Синтез:**
  * Синусоидальные микро-тоны с межфазным интервалом 28 мс.
  * При активации (`active = true`): восходящая пара частот `[280, 420] Гц`.
  * При деактивации (`active = false`): нисходящая пара частот `[400, 240] Гц`.
  * Быстрое экспоненциальное затухание каждой фазы за 22 мс.

### 4. Выдох оперативки / Выдувание шума (`playCalmExhale()`)
* **Физическая модель:** Мягкий воздушный поток сверху вниз без резких частот.
* **Синтез:**
  * Генерация шумового буфера длительностью 280 мс.
  * Динамический Low-Pass фильтр: экспоненциальный спад частоты среза от 750 Гц до 160 Гц.
  * Плавное нарастание громкости (50 мс атака) и мягкий спад до нуля.

## 4. Управление и доступность

* **Отключение в 1 клик:** Пользователь может в любой момент выключить или включить звуки в разделе «Общие» панели настроек ([`src/Settings.tsx`](file:///d:/dev/tools/browser/src/Settings.tsx)) или через `sound.toggle()`. Состояние сохраняется локально в ключе `dombro:sound-enabled`.
* **Отказоустойчивость:** Если Web Audio API недоступен (например, в среде тестов JSDOM или при политике блокировки автовоспроизведения браузера), методы движка безопасно завершаются без ошибок и без прерывания пользовательских сценариев.
