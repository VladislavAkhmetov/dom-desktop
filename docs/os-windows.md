# Наблюдатель за окнами Windows и привязка программ к Кабинетам (os-windows)

> **Назначение документа:** Архитектурная спецификация модуля взаимодействия с окнами операционной системы Windows 11 через FFI-библиотеку `koffi` в главном процессе Electron.

---

## 1. Концепция и цель подсистемы

В рамках философии **Calm Tech** и концепции Кабинетов (Spaces) рабочий процесс пользователя не ограничивается веб-вкладками. Дизайнеры, разработчики и аналитики используют сторонний софт (Adobe Illustrator, Photoshop, Figma Desktop, VS Code, Word, CAD-системы).

Ранее запуск внешних файлов производился «в один конец» через `shell.openPath`: приложение dombro не знало о судьбе запущенного процесса, его окнах и не могло координировать их видимость при переключении контекстов.

Модуль `electron/os-windows.cjs` превращает главный процесс Electron в деликатного наблюдателя за окнами Windows, позволяя:
1. Выбирать и привязывать запущенные в Windows окна к материалам конкретного Кабинета (`kind: 'window'`).
2. Автоматически сворачивать связанные окна при парковке Кабинета (`parkSpace`) без затрагивания окон, нужных другим пространствам.
3. Разворачивать привязанные окна при продолжении работы (`openWorkstage`, карточка `ResumeCard`).
4. Мягко перезапускать программу по сохранённому пути `target` (`exePath`), если окно было закрыто пользователем или сессия завершена.

## 3. Критерии фильтрации окон Win32 (Чистый список без фантомов)

В Windows 11 насчитывается от 300 до 600 окон, большинство из которых являются служебными (фоновые UWP, оверлеи Nvidia/Discord, DDE-серверы, системные треи).

Чтобы сформировать чистый список пользовательских приложений, модуль применяет многоуровневую фильтрацию:
1. **Видимость:** `IsWindowVisible(hwnd)`.
2. **Изоляция своего процесса:** `pid !== process.pid` (исключает окна самого dombro даже в режиме разработки `electron.exe`).
3. **DWM Cloaked:** `DwmGetWindowAttribute(hwnd, DWMWA_CLOAKED, ...)` отсекает фоновые оболочки UWP и окна других виртуальных рабочих столов Windows 11.
4. **Стили таскбара:** окна с расширенным стилем `WS_EX_TOOLWINDOW` исключаются, если не имеют явного стиля `WS_EX_APPWINDOW`.
5. **Геометрия:** для несвёрнутых окон проверяется `GetWindowRect` (ширина и высота > 0).
6. **Заголовок:** исключаются окна без заголовка, а также системный `Program Manager`.
7. **Путь и имя `.exe`:** через `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, ...)` и `QueryFullProcessImageNameW` извлекается путь к файлу. Процессы `ApplicationFrameHost.exe` исключаются.

## 4. Безопасность фокуса и многооконность (SetForegroundWindow)

В Windows действует системное ограничение **Foreground Lockout**: фоновый процесс не может вытолкнуть окно на передний план.

* При нажатии на карточку продолжения в dombro сам dombro является активным процессом переднего плана.
* Если к Кабинету привязано несколько окон (например, Illustrator и Photoshop), вызов `SetForegroundWindow` для первого окна лишил бы dombro прав переднего плана, заставив второе окно мигать оранжевым цветом на панели задач.
* **Решение:** все привязанные окна сначала разворачиваются флагом `ShowWindow(SW_RESTORE)`, а `SetForegroundWindow` вызывается один раз в конце — передавая фокус либо окну dombro (чтобы окна раскрылись фоном за рабочей средой), либо последнему активированному приложению.

## 5. Модель данных

Ресурс типа `'window'` расширяет интерфейс `Resource`:

```typescript
export interface Resource {
  id: string
  name: string                 // Заголовок окна на момент привязки
  kind: 'window' | ...
  target: string               // Полный путь к exe-файлу (exePath)
  exeName?: string             // Имя файла процесса (Illustrator.exe)
  windowHwnd?: string          // Системный идентификатор окна в текущей сессии ('0x123abc')
  windowTitle?: string         // Заголовок окна
  createdAt: string
  ...
}
```

Если сессия завершена, компьютер перезагружен или окно закрыто пользователем:
* `osWindows.isWindowAlive(windowHwnd)` возвращает `false`.
* Обработчик `resource:open` в `main.cjs` бесшовно запускает сохранённый `target` (`shell.openPath(resource.target)`), не порождая ошибок.
