# Спокойные анимации dombro

Движение подключено к существующим компонентам dombro. Цвета, шрифты, размеры и расположение элементов задаются прежними стилями проекта. Анимация объясняет смену контекста; фон не движется, поверхности не отскакивают.

Основа — [Fluid Functionalism Motion](https://www.fluidfunctionalism.com/docs/motion), [Tabs](https://www.fluidfunctionalism.com/docs/tabs) и [публичные параметры пружин](https://www.fluidfunctionalism.com/r/springs.json). Реализация адаптирована к React-компонентам проекта через библиотеку Motion; компоненты shadcn, Radix и оформление сайта не устанавливаются.

## Подключённые движения

- Верхняя навигация и разделы настроек: общий индикатор выбора и подсветка ближайшей к курсору кнопки. Подсветка меню также следует за клавиатурным фокусом.
- Меню действий и контекстное меню: появление и закрытие панели, движение подсветки между действиями.
- Быстрый ввод: появление и закрытие над нижней капсулой. Переключение записи и ИИ сохраняет один экземпляр панели и отдельные черновики.
- Кнопки «Записать», «Спросить ИИ», «Фокус» и «Продолжить»: общий отклик нажатия (`pressOpacity`).
- Общий Dialog: мягкое появление окна без отскока. Закрытие модальных окон пока остаётся мгновенным; меню и быстрый ввод имеют анимированный выход.
- Вход из дашборда в браузер: область вкладок раскрывается до размера окна за `--motion-layout` (320 мс) по `--ease-calm`. При открытии отдельной вкладки источником становится её карточка, при продолжении с главной — карточка продолжения. Внутренняя поверхность меняет масштаб только на 1,5%; название пространства перемещается в верхнюю панель браузера. При возврате поверхность сворачивается, восстанавливая прокрутку и фокус в дашборде.

## ДНК микроанимаций

Одна кривая, шесть длительностей, одно появление. Движение должно ощущаться — медленное, мягкое скольжение, а не мелькание: первая версия (160–240 мс, сдвиг 4px) была почти незаметна и не давала ощущения спокойствия. Всё движение в проекте собирается из этих значений; новое правило без них считается ошибкой (тест `tests/motion-dna.test.ts`).

**Принципы.** Движение объясняет, что произошло, и не привлекает к себе внимания. Ничего не отскакивает и не перелетает (пружины только с `bounce: 0`). Уверенный старт и длинное тихое торможение: элемент «садится» на место, а не прилетает. Уход быстрее прихода. Одинаковые действия выглядят одинаково во всех разделах.

### Токены (`src/motion.css`, зеркало для Motion/WAAPI — `src/motion.ts`)

| Токен | Значение | Для чего |
|---|---|---|
| `--ease-calm` | `cubic-bezier(0.32, 0.72, 0, 1)` (кривая шторок iOS) | всё, что появляется, меняется или перемещается |
| `--ease-exit` | `cubic-bezier(0.4, 0, 0.7, 0.2)` | уход панелей (ускоряется и не задерживается) |
| `--ease-breathe` | `cubic-bezier(0.4, 0, 0.6, 1)` | только циклы «идёт работа» |
| `--motion-press` | 120 мс | отклик нажатия |
| `--motion-hover` | 240 мс | наведение и фокус: цвет, фон, рамка, тень, прозрачность |
| `--motion-state` | 320 мс | выбор, переключатели, шевроны, индикаторы внутри контрола |
| `--motion-enter` | 420 мс | появление меню, поповеров, тостов, панелей |
| `--motion-exit` | 240 мс | их уход |
| `--motion-layout` | 480 мс | изменение размеров, вход экрана, переход дашборд ↔ браузер |
| `--motion-stagger` | 50 мс | шаг между соседями, появляющимися вместе (не больше шести шагов) |
| `--motion-spin` / `--motion-breathe` | 1 с / 3,2 с | спиннер (linear) / пульс живого состояния |
| `--enter-y`, `--enter-x`, `--enter-scale` | 8px, 0, 1 | дистанция появления; у панелей под кнопкой — `-8px` и `.97`, над кнопкой — `8px` и `.97` |
| `--press-opacity` | .88 | нажатие (вместо масштаба) |

### Правила

1. **Наведение и нажатие не двигают и не масштабируют** (масштаб размывает текст на субпикселях). Только цвет, фон, рамка, тень, прозрачность за `--motion-hover`. Исключение — направленная стрелка в главной кнопке: сдвиг на 2px.
2. **Нажатие — одно для всех:** `opacity: var(--press-opacity)` за `--motion-press`; у `FluidButton` — `whileTap={{ opacity: pressOpacity }}`.
3. **Появление — один keyframe `calm-in`:** прозрачность + сдвиг на 8px (+ масштаб .97 у панелей, привязанных к кнопке), `--motion-enter`, `--ease-calm`, `both`. Направление задаётся переменными `--enter-y`/`--enter-x` на элементе. `calm-in` анимирует отдельные свойства `translate`/`scale`, поэтому складывается с собственным `transform` элемента (например, центрирование `translateX(-50%)`).
4. **Уход** — через Motion: `fluidExit` (160 мс, `--ease-exit`), сдвиг вдвое меньше появления.
5. **Нет `transition: all`.** Свойства перечисляются явно; размеры (`width`, `height`) анимируются только для намеренного раскрытия, за `--motion-state`/`--motion-layout`.
6. **Циклы — только когда что-то действительно происходит** (загрузка, запись, фокус, играет музыка): `calm-spin` (linear), `calm-breathe` (прозрачность, без масштаба больше 1).
7. **Motion по умолчанию спокойный:** `MotionConfig` в `main.tsx` задаёт `calmTween()` всем `motion.*` без явного `transition` (иначе Motion использует пружину с перелётом) и `reducedMotion="user"`.
8. **Уменьшение движения:** при `prefers-reduced-motion` дистанции и масштаб обнуляются, `--motion-state` и `--motion-layout` становятся мгновенными, остаются только растворения; глобальные правила в `ui.css`/`glass.css` отключают циклы.
9. **Вход экрана** (`src/useScreenEntrance.ts`): при смене раздела хаба («Мой день», «Пространства», страница пространства) блоки экрана — шапка, «Порог», карточки — поднимаются на 8px и проявляются по очереди (`--motion-layout`, шаг `--motion-stagger`, не больше шести шагов). Анимируется каждый блок, а не общая обёртка: прозрачность у родителя делает его backdrop root и выключает стекло (`backdrop-filter`) у карточек внутри — в конце перехода стекло «щёлкало» бы обратно. По той же причине в появлениях нет `filter: blur`. Без перемонтирования (WAAPI), во время пространственного перехода в браузер не запускается.

10. **Звонок напоминания** (`.island-trigger.is-ringing`): иконка острова качается, как маленький подвешенный колокольчик (ось сверху, затухание −14° → 11° → −7° → 4° → −2°, два качания по `--motion-ring` 1,1 с, `--ease-breathe`), вокруг капсулы один раз расходится акцентный ореол. Потом тишина — «Сейчас» остаётся в острове. Только при свежем сроке, один раз; при уменьшении движения анимации нет, остаётся звук.

**Осознанные исключения** (медленнее 450 мс, не отклик интерфейса): темп дыхательного упражнения (4 с), таймер фокуса (1 с, linear), побуквенное приветствие (450 мс). Отдельные keyframes остаются только у живых состояний: `calm-voice-pulse` (запись), `calmWave` (эквалайзер), `gentlePulse` (фокус), `island-bell` и `island-halo` (звонок напоминания), `tab-peek-fade` (reduced motion).

### Библиотеки

Анимации строятся на [Motion](https://motion.dev) (бывший Framer Motion, MIT) — ведущей бесплатной библиотеке анимаций для React; она уже в проекте (`FluidGroup`, `FluidSurface`, `Dialog`, стопка обложек, `AnimatePresence`). Вторую библиотеку не добавляем: ощущение «почти незаметно» давали значения, а не инструмент. CSS-переходы и WAAPI берут те же токены.

### Что было приведено к ДНК

* 203 объявления `transition` в 36 CSS-файлах: около 25 разных длительностей (80–450 мс) и 9 кривых, включая резкие expo-кривые `cubic-bezier(.16,1,.3,1)`, заменены токенами; 40 `transition: all` раскрыты в явные свойства.
* 55 правил движения при наведении/нажатии: подъёмы на 1–5px, увеличение до ×1.12, сжатие до ×0.94. Подъёмы и увеличения убраны, сжатия при нажатии заменены общей прозрачностью `--press-opacity`, веер листов в обзоре пространств приглушён.
* 25 одноразовых `@keyframes` (сдвиги 4–14px, масштаб от .8) заменены общими `calm-in`, `calm-spin`, `calm-breathe`.
* Motion: пружины с перелётом (stiffness 350–380, затухание ≈0,85) у карточки «Продолжить» и стопки обложек, падение обложек с 40px, растворение заметки на 26px, 600 мс у волны облегчения, разные сдвиги у Dialog/панелей — всё через `fluidSpring`, `calmTween`, `enterOffset`. Пространственный переход дашборд ↔ браузер использует ту же кривую и `--motion-layout`.

## Переход и живые страницы

Маршрут переключается сразу, без таймера перед открытием. Над живым интерфейсом находятся временные DOM-снимки с `inert`, `aria-hidden` и `pointer-events: none`. Новый ввод, обычный клик, прокрутка, изменение размеров окна или уход приложения в фон завершает переход. Быстрый возврат кнопками «Вернуться в дашборд» / «Открыть вкладки» разворачивает текущую анимацию с её текущей позиции.

Electron WebContentsView работает вне DOM. Перед открытием переход временно скрывает нативное представление; загрузка страницы начинается сразу на её конечных размерах. Движутся снимки оболочки и доступное превью страницы, а живая страница сохраняется в BrowserManager. По завершении она снова видима. При первом открытии, пока превью ещё нет, раскрывается оболочка браузера. Для локальных страниц веб-демо используется изолированная копия DOM в Shadow DOM со стилями и изображениями. Снимки не запускают дополнительные iframe и скрипты и не читают страницы другого origin.

## Проверка

Открыть `http://127.0.0.1:5173/?cabinet=1&demo=1` после `npm run dev:web`. Выбрать пространство, нажать «Открыть вкладки», затем «Вернуться в дашборд». Проверить быстрый возврат, открытие отдельной вкладки и сохранение прокрутки. Для проверки уменьшения движения включить системную настройку анимаций Windows либо эмуляцию `prefers-reduced-motion: reduce` в DevTools.

Сборка: `npm run build`. Проверки поведения: `npm run test:unit -- tests/motion-dna.test.ts tests/workspace-transition.test.tsx tests/fluid-motion.test.tsx tests/cabinet-app.test.tsx tests/capture.test.tsx tests/settings.test.tsx tests/profile.test.tsx tests/resume-app.test.tsx tests/tab-overview.test.tsx tests/news.test.tsx tests/workstage-tabs.test.tsx`. Нативный сценарий: `npm run test:cabinet-native` проверяет открытие живой страницы, окончательные размеры WebContentsView и сохранение ввода после возврата и повторного входа.
