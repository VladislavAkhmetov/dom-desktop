# Дом — настольный прототип

Спокойный стартовый экран для Windows. Интерфейс занимает один холст без прокрутки: карточки, пространства и ресурсы открываются в пределах окна; длинные списки разбиты на страницы. В первой версии есть ярлыки приложений, документов и сайтов, подсказка вернуться к открытому через Дом файлу и локальные напоминания. Генеративный ИИ и внешние аккаунты в работе приложения не используются.

## Запуск

Нужны Node.js 22.12+ и npm. В папке проекта:

```powershell
npm install
npm run dev
```

Для проверки собранного интерфейса:

```powershell
npm run build
npm start
```

## Сборка десктопного приложения (.exe)

Для упаковки приложения в standalone Windows-дистрибутивы:

- **Быстрая сборка в папку без архивации**:
  ```powershell
  npm run pack
  ```
  Создаёт готовую к запуску папку `release/win-unpacked/Дом.exe`.

- **Портативная версия (.exe)**:
  ```powershell
  npm run dist:portable
  ```
  Создаёт один файл `release/Дом-0.1.0-Portable.exe`, работающий без установки.

- **Полноценный установщик Windows (NSIS-инсталлятор)**:
  ```powershell
  npm run dist:setup
  ```
  Создаёт мастер установки `release/Дом-Setup-0.1.0.exe` с ярлыками на Рабочем столе и в меню «Пуск».

- **Собрать всё сразу (инсталлятор + portable)**:
  ```powershell
  npm run dist
  ```

Окно закрывается в область уведомлений, чтобы напоминания продолжали работать. Полностью закрыть приложение можно через меню значка «Дом» в области уведомлений. Быстрый ввод открывается сочетанием **Ctrl + Alt + Space**.

## Что уже работает

- Создание пространств; добавление сайтов, документов и приложений; открытие ресурсов через Windows.
- При первом запуске Дом добавляет ярлыки Figma и Adobe Illustrator 2025, если находит эти приложения на компьютере. Повторно ярлыки не создаются.
- Карточка погоды показывает текущую температуру в Уфе через Open-Meteo и хранит последний ответ до часа. Карточка дорог открывает карту Уфы с дорожным слоем Яндекс Карт; численную оценку пробок приложение пока не показывает.
- Локальная история открытия файлов через Дом: на главной появляется предложение продолжить работу. «Закончено» и «Позже» управляются пользователем.
- Свободный текст напоминания с распознаванием «сегодня», «завтра», даты, времени и интервалов «через N минут/часов» по простым правилам. Перед сохранением результат можно исправить.
- Системное уведомление для напоминания с указанным временем, пока приложение запущено.
- Необязательный автозапуск после входа в Windows.
- Просмотр интерфейса в обычном браузере через Vite. В этом режиме локально сохраняются пространства и ссылки, но открытие программ и файлов доступно только в Electron.

## Границы прототипа

- Голосовой ввод сейчас использует системную диктовку Windows (**Win + H**) в поле быстрого ввода. Приложение не записывает и не хранит аудио.
- Пространства хранят собственные вкладки-ссылки. Адресная строка создаёт или меняет текущую вкладку, а ссылку можно добавить в материалы пространства. Сайты открываются в браузере по умолчанию; встроенный просмотр страниц остаётся отдельным этапом.
- Дом знает, какой документ пользователь открыл через него. Он не считывает состояние Illustrator и не решает сам, закончен ли файл.
- Напоминания локальны на одном компьютере. Синхронизации, почты, мессенджеров и календаря пока нет.
- Погода требует сети. При недоступном источнике Дом показывает отсутствие данных, не подставляя придуманную температуру.

Данные Electron хранятся в `state.json` внутри пользовательской папки данных приложения. Четыре исходных референса и принципы дизайна находятся в [визуальном мудборде](./assets/moodboard/index.html) и его [пояснении](./assets/moodboard/README.md).

Фоновое изображение прототипа — отдельный статичный ассет `public/meadow-background-v2.png`, созданный для проекта. Оно не требует ИИ или сети при запуске приложения.
