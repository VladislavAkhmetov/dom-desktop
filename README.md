# Дом — браузер и спокойный дашборд

Дом сохраняет контекст работы, помогает выбрать следующее действие и держит материалы по пространствам. Эта итерация проверяется в Chrome; сборка Windows отложена. Локальные модели ИИ в неё не входят.

## Запуск в Chrome

Нужны Node.js 22.12+ и npm. Из папки проекта:

```powershell
npm install
npm run dev:web
```

Открыть [личный режим](http://127.0.0.1:5173/) или [пример дня](http://127.0.0.1:5173/?demo=1). Команда `dev:web` запускает только Vite. `npm run dev` дополнительно открывает Electron и сейчас не нужна для браузерной проверки.

Пример дня хранится в sessionStorage отдельно от личных записей. Письма и статьи в нём вымышлены и помечены как примеры. «Настройки → Начать заново» сбрасывает только пример. В Chrome личные данные хранятся в IndexedDB; прежний localStorage мигрируется при чтении.

## Главная и ежедневные действия

- Крупная дата открывает календарь. Дела можно смотреть списком, неделей и месяцем.
- Карточка продолжения показывает сохранённый следующий шаг конкретного пространства. Состояние каждого проекта сохраняется отдельно, с историей до 20 сохранений.
- «Оставить на завтра» сохраняет контекст и переносит только отмеченные пользователем дела. Отмена восстанавливает продолжение и даты.
- День выполнения, срок и время напоминания — отдельные поля. Фраза «завтра проверить макет» создаёт дело на завтра без автоматического таймера.
- Быстрый ввод сохраняет по Enter. Shift + Enter добавляет строку; многострочный текст можно сохранить через Ctrl/Cmd + Enter. Расширенное окно также поддерживает Ctrl/Cmd + Enter. Черновики сохраняются в пределах браузерной сессии.
- «Одно дело» оставляет продолжение, одно дело и быструю запись. Прочие карточки остаются в настройках и возвращаются в режиме обзора.
- «Настроить главную» меняет размер S/M/L, порядок и набор карточек. Можно скрыть карточку, отменить изменение и вернуть стандартную раскладку. Для дайджеста отдельно выбираются заголовки, краткие описания или подробные фрагменты.

Island показывает один актуальный сигнал: напоминание, выбранное уведомление встречи, фокус или важное письмо. Завершение дела в island можно отменить. Живые подсказки включаются отдельно и выполняют одно короткое движение; CSS учитывает prefers-reduced-motion.

## Пространства и вкладки

У каждого пространства есть материалы, набор вкладок и сохранённое продолжение. Вкладки расположены сбоку, их можно искать, закреплять, закрывать, возвращать после закрытия и открывать рядом. «Сохранить и прибрать» оставляет точку продолжения и возвращает на главную.

Импорт принимает список HTTP/HTTPS-адресов, HTML-закладки и JSON с окнами Chrome, закреплением и группами. Вставленный набор показывается до добавления. Страницы загружаются при открытии, а не во время импорта. Отдельный экспортёр лежит в `chrome-export`; его установка и проверка на реальных вкладках пока не выполнены.

В Chrome встроенная страница заменена честным предложением открыть сайт в соседней вкладке. Просмотр чужих сайтов внутри приложения, сохранение введённых форм при переключении и защита страниц от закрытия реализованы в Electron через WebContentsView. Введённые формы сохраняются в живом процессе; после полного перезапуска браузера восстановление их содержимого не обещается. cookies и браузерные профили Chrome в Дом не импортируются.

Поиск Ctrl/Cmd + K находит названия пространств и материалов, адреса вкладок, дела и следующий шаг. Это поиск по метаданным, а не по всему содержимому сайтов и файлов. Файл из результатов сохраняет свой тип; дело открывается для редактирования.

## Календарь, почта и новости

ICS-подписки поддерживают повторения, исключения, VTIMEZONE/IANA, переходы времени и события на весь день. Ошибка обновления не уничтожает сохранённые события. В Chrome источник должен разрешать запрос из браузера; часть внешних календарей и RSS ограничена CORS.

Gmail в Electron использует OAuth Desktop app с PKCE и loopback, только scope gmail.readonly. Подключаются несколько аккаунтов. Начальная синхронизация читает до 100 входящих, затем используется history; локальный кеш ограничен 500 письмами на аккаунт. Сохраняются метаданные и snippet, а не полный текст письма. Можно выделять важных отправителей, открыть оригинал или создать дело из письма. Полный OAuth-проход с настоящим аккаунтом и проверка приложения Google ещё не выполнены. В веб-режиме подключение Gmail недоступно.

RSS и Atom собираются в конечный выпуск до 30 материалов, с историей до 7 выпусков. По умолчанию новый выпуск собирается раз в день, пока Дом открыт; есть ручное обновление. Открытый выпуск не меняется во время чтения. После его закрытия карточка показывает актуальный выпуск. Ошибка источника видна в настройках; прежний выпуск остаётся доступным.

Для локальной проверки RSS в настройках можно указать адрес `http://127.0.0.1:5173/qa/fixtures/feed.xml`. Это явно вымышленная тестовая лента.

## Облачный ИИ

В Electron подготовлены OpenAI Responses, Anthropic Messages и совместимый HTTPS endpoint. Пользователь задаёт собственные ключ и модель, выбирает роль: чат, помощник или ассистент. Основные сценарии работают без ИИ.

Контекст добавляется явно: выбранная страница, материалы, дела, фрагменты писем или выпуск новостей. Перед отправкой видно, какие источники включены, и требуется согласие. Для страницы можно передать выделенный текст либо доступный текст страницы. Чтение файлов ограничено поддерживаемыми текстовыми форматами; PDF, Office и Adobe-файлы пока не извлекаются.

ИИ может предложить три внутренних действия: создать дело, сохранить HTTP/HTTPS-ссылку и оставить следующий шаг существующего пространства. Каждое применяется отдельной кнопкой. Отправка писем, удаление данных и произвольные команды не входят в инструменты. Доверенность текста сайта не заменяет пользовательское разрешение.

Фоновые обзоры включаются отдельно и используют только важные непрочитанные snippets и фрагменты новостей. Настраиваются дневной лимит числа запросов и максимальное число выходных токенов. Это технические ограничения, а не точный денежный бюджет. Журнал хранит статус, источники, результат и сообщённое провайдером использование токенов.

В Chrome подключение ключей и реальные запросы ИИ недоступны. Адаптеры проверены тестовыми потоками; реальные вызовы всех трёх провайдеров ещё требуют проверки с ключами владельца.

## Данные Electron

Состояние находится в `dom.sqlite` внутри app.getPath('userData'). Запись выполняет отдельный работник, изменения применяются транзакционно. SQLite FTS5 индексирует метаданные. Прежний `state.json` мигрируется, а исходник сохраняется как `state.json.before-sqlite`. Повреждённый файл не перезаписывается пустым состоянием.

На запуске создаётся `dom.previous.sqlite`; ручная копия — `dom.manual.sqlite`. Автоматическое восстановление из произвольной копии пока не добавлено.

Ключи API, OAuth-токены и новые секретные iCal-адреса хранятся в `secrets.encrypted.json` через safeStorage. При недоступном шифровании сохранение секрета отклоняется. Резервные копии и исходный JSON, созданные до переноса старых iCal-адресов, могут содержать эти адреса; автоматически старые файлы не удаляются. Локальная база с делами, фрагментами писем и ответами ИИ целиком не шифруется.

Системные уведомления и фоновая синхронизация работают, пока Electron запущен. Закрытие окна оставляет приложение в трее Windows; полное завершение — через меню трея. Глобальная запись: Ctrl + Alt + Space на Windows, Cmd + Option + Space на macOS. Подготовка macOS ещё не проверена на реальном Mac.

## Проверки

```powershell
npm test
npm run build
```

`npm test` запускает Vitest и проверку SQLite через Electron в режиме Node без окна. `npm run build` проверяет TypeScript и собирает веб-ресурсы; Windows-приложение эта команда не упаковывает.

Нативная проверка браузера — `npm run test:browser`; она запускает скрытый Electron и сейчас отделена от текущей приёмки в Chrome. Упаковочные команды сохранены в package.json, но актуальный Windows-дистрибутив не создаётся до возвращения к этому этапу.
