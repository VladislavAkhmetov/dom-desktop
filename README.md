# dombro — браузер и спокойный дашборд

dombro сохраняет контекст работы, помогает выбрать следующее действие и держит материалы по пространствам. Доступен как в веб-режиме, так и в виде настольного приложения на Electron для Windows 11.

## Настольный пилот: Кабинеты в Electron

Согласованный UX кабинетов (пространств без вложенных дел, с сохранением каркаса дашборда и открытием нативного браузера только при явных действиях) подключён к Electron и доступен в виде автономной сборки.

### Запуск готовой Portable-версии для Windows 11
Один файл, имя берётся из версии в `package.json`:
```powershell
.\release\dombro-0.0.1-Portable.exe
```
Запуск не требует установки. Приложение открывается со своей базой SQLite и заставкой, на которой версия показывается как `v` плюс номер из сборки (сейчас `v0.0.1`). Карточка и окно проявляются растворением, без скачка на весь экран. Режим кабинетов включён в этом же файле.

### Сборка и упаковка в Electron
```powershell
# Сборка распакованного каталога приложения (release/win-unpacked):
npm run pack

# Один переносимый файл (release/dombro-<version>-Portable.exe):
npm run dist:portable

# Сборка NSIS инсталлятора с генерацией дифференциальных .blockmap:
npm run dist:setup

# Запуск полного набора проверок и тестов упакованного бинарника:
node scripts/test-packaged.cjs release/win-unpacked/dombro.exe
node scripts/verify-portable-live.cjs
```

### Публичные релизы и автообновление (Calm Tech)

Приложение настроено на автоматическую публикацию релизов в публичный репозиторий `owner/dombro-releases` с дифференциальными пакетами `.blockmap` (таргет NSIS).

* **Спокойное автообновление:** фоновая проверка запускается через 10 секунд после старта приложения, не замедляя холодный запуск.
* **Без навязчивых баннеров:** при загрузке обновления на островке внимания появляется самый низкоприоритетный сигнал: `Доступно обновление dombro · Перезапустить при выходе`.
* **Установка при выходе:** обновление безопасно устанавливается при закрытии приложения в конце дня без принудительных перезапусков.

## Запуск в Chrome (веб-версия)

Нужны Node.js 22.12+ и npm. Из папки проекта:

```powershell
npm install
npm run dev:web
```

Открыть [личный режим](http://127.0.0.1:5173/) или [пример дня с кабинетами](http://127.0.0.1:5173/?cabinet=1&demo=1).

## Концепция: пространство как кабинет

Новый UX убирает вложенное «Дело», создаёт пустое пространство без формы имени и показывает материалы рядом с браузером.
Выбор, создание и продолжение пространства в дашборде сохраняют его каркас. Только явное открытие браузера или вкладок раскрывает браузерный режим; возврат ведёт в прежний раздел дашборда.

В выбранном пространстве теперь видны сами вкладки, конкретные документы и отдельные инструменты. Есть поиск, фильтры, меню по правой кнопке и перестановка пространств. Вкладку можно перетащить в другое пространство, а документ — добавить туда же без удаления исходной ссылки. Необязательные миниатюры используют готовые снимки просмотренных страниц из памяти Electron; веб-пилот не загружает сайты ради превью и не сохраняет изображения в БД. Подробности проверки и границы нативного подключения — в [qa/CABINET-DASHBOARD.md](qa/CABINET-DASHBOARD.md). Для уже собранного portable-приложения требуется пересборка.

Полная продуктовая сводка, правила документов и памяти, гипотезы и этапы «браузер → Windows 11 → macOS» находятся в [docs/cabinet-upgrade.md](docs/cabinet-upgrade.md). Архитектурные детали — в [ARCHITECTURE.md](ARCHITECTURE.md). Описанное ниже прежнее поведение сохраняется в режиме без `cabinet=1`. В пилоте реализована безопасная выгрузка неактивных вкладок из ОЗУ (`park`) с сохранением воспроизведения звука и незавершенных форм, а также мгновенным восстановлением из снимка страницы. Локальный ИИ в текущий пилот не входит.

Пример дня хранится в sessionStorage отдельно от личных записей. Письма в нём вымышлены и помечены как примеры; новости загружаются из настоящих RSS с изображениями и рубриками. Сохранённый старый пример автоматически подключает источники и убирает вымышленные статьи, сохраняя изменения дел и пространств. «Настройки → Начать заново» сбрасывает только пример. В Chrome личные данные хранятся в IndexedDB; прежний localStorage мигрируется при чтении.

## Главная и ежедневные действия

- Крупная дата и время в верхней полосе дашборда выдержаны в едином сосново-зелёном тоне (`#294d43`), выровнены строго по одной верхней линии и дополнены гармоничными вторичными подписями (`#34574b`) дня недели и погоды (`Уфа 0°`). Клик по дате открывает интерактивный календарь месяца, по погоде — прогноз.
- **Сбалансированный стартовый экран (3 карточки по умолчанию):**
  - **«Продолжить»** — закреплена в левом верхнем углу: мгновенно возвращает в активный Кабинет, открывая вкладки, связанные файлы и окна программ Windows.
  - **«Дела»** — фокус на сегодняшних и завтрашних задачах без информационного шума.
  - **«Почитать» (закладки на потом)** — полка сохранённых ссылок и рабочих материалов под задачу с расчётом времени чтения. Поддерживает 2 режима отображения (комфортный список и адаптивные плитки с квадратными обложками), плавный скроллбар с градиентным размытием краёв и быструю порционную подгрузку без лагов.
- **Опциональный дайджест новостей и парковка сырых виджетов:**
  - Карточка «Дайджест» отключена по умолчанию для предотвращения цифровой тревожности (Calm Tech), но доступна для добавления в один клик через кнопку `+ Добавить виджет`.
  - Сырые и второстепенные виджеты (`Почта`, `Карты`, `Забота и привычки`, большая карточка погоды) припаркованы до будущих релизов.
- **Безопасное автозаполнение и сохранение паролей (Calm Tech):**
  - При отправке формы входа (`submit`) браузер предлагает сохранить связку логин/пароль в аккуратном выпадающем баббле у адресной строки. Фонового кейлоггинга нет: считывание происходит только при отправке, а происхождение (`origin`) валидируется главным процессом против реального `webContents.getURL()`.
  - Все учетные записи шифруются системным `safeStorage` (Windows DPAPI / macOS Keychain) в `secrets.encrypted.json`.
  - В строке адреса появляется кнопка-ключик 🔑 при наличии сохранённых учетных записей для текущего сайта — автозаполнение вставляется в форму в один клик.
  - В настройках («Пароли и ключи») доступны просмотр, редактирование, а также экспорт/импорт в CSV Bitwarden для синхронизации со смартфонами и другими устройствами. Официальное расширение Bitwarden в рантайме Electron 41 не запускается, поэтому встроенный Vault берет на себя локальное удобство серфинга без сторонних расширений.
- Главный омнибокс на дашборде оснащён быстрым автодополнением с подсказками Google, открытыми вкладками пространств, историей и закладками. Рядом с вкладками пространств размещена отдельная кнопка поиска по пространствам (`Ctrl+K`).
- Вкладки рабочих пространств (Chrome-like Tab Strip): таб «Мой день» зафиксирован на левом краю как постоянный вход в домашний дашборд. Все пространства отображаются в полосе вкладок с плавной горизонтальной прокруткой и бесшовным градиентным растворением краев (CSS mask-image). Поддерживается интерактивное перетаскивание вкладок (браузерный drag & drop) мышью и HTML5 с живым раздвиганием соседних табов в реальном времени, полупрозрачным превью, автоскроллом у краев и отменой по Escape. Управляющие элементы («Все пространства», «+», поиск) вынесены в защищённый блок действий справа, который никогда не сжимается и не выталкивается за пределы экрана. Навигационные стрелки влево/вправо оформлены в виде круглых стеклянных кнопок на соответствующих краях полосы вкладок без непрозрачных подложек и активируются только при наличии скрытых пространств. Поддерживается непрерывный скролл при зажатии стрелок, прокрутка колесиком мыши и автоматическое центрирование активного пространства.
- Каталог пространств («Все пространства»): карточки пространств снабжены круглым стеклянным меню «три точки» в правом верхнем углу (симметрично нижней стрелке перехода) для быстрого переименования, закрепления в полосе табов, перемещения, архивации и удаления без случайного открытия пространства.
- В одном пространстве могут быть разные дела. В браузере их выбирают над вкладками; в материалах пространства показано текущее дело для открываемых документов. История содержит до 20 сохранений пространства, заметки и снимки относятся к своему делу.
- Вкладки автоматически сохраняются в текущем деле. Документ присоединяется после успешного открытия из Дома; сохранение файла или ссылки в материалы само по себе не включает их в продолжение. Можно явно выбрать документы в настройке карточки. Сохраняются пути к файлам, а не копии содержимого; сохранением изменений занимается редактор документа.
- Продолжение сохраняет другие группы и не заменяет живые вкладки старым снимком. «Сохранить и вернуться» скрывает страницы без закрытия. При частичной ошибке повторяются только неоткрытые документы; повторное нажатие во время открытия блокируется.
- В Windows документы открываются через системную программу по умолчанию. В кабинетах доступна привязка запущенных окон Windows (Photoshop, Illustrator, Figma, VS Code и др.) к материалам пространства с аккуратным сворачиванием при парковке и разворачиванием при продолжении работы. Автоматическая скрытая автосцепка без ведома пользователя исключена в соответствии с принципами спокойного интерфейса. В Chrome локальные файлы не запускаются; группа показывается в веб-прототипе. Подробности — в [описании карточки](docs/resume-card-ux.md) и [документации оконных ресурсов](docs/os-windows.md).
- День выполнения, срок и время напоминания — отдельные поля. Фраза «завтра проверить макет» создаёт дело на завтра без автоматического таймера.
- Голосовой ввод (Push-to-Talk) и быстрая запись: по шорткату `Ctrl+Shift+Space` (`Cmd+Shift+Space` на macOS) вызывается окно записи, где доступна кнопка микрофона и шорткат `Ctrl+Shift+V`. Запись активна строго во время диктовки (0% нагрузки в фоне, микрофон сразу освобождается). Распознанный текст автоматически разбирается парсером дат и времени («через 20 минут», «завтра в 14:00») и выводится в спокойный предпросмотр перед сохранением.
- «Записать» и «Спросить ИИ» в нижней капсуле открывают поле над ней. Режимы сохраняют отдельные черновики; Escape закрывает поле и возвращает фокус на кнопку. Быстрый ввод сохраняет по Enter. Shift + Enter добавляет строку; многострочный текст можно сохранить через Ctrl/Cmd + Enter. Черновики сохраняются в пределах браузерной сессии.
- Единый стандарт карточек дашборда (dombro UI Kit):
  - **Плотные светлые подложки и естественная высота:** мягкий тёплый оттенок слоновой кости (`rgba(247, 248, 243, 0.96)`) с отступами 28px внутри карточек и 20–24px между смысловыми блоками. Высота карточек зависит от контента (`height: auto`). Плотная подложка защищает текст от ярких обоев рабочего стола.
  - **Отказ от вложенных плашек:** вокруг отдельных задач, заметок и материалов убраны контрастные фоновые подложки; строки разделены естественным воздухом и тонкими разделительными линиями (`1px solid rgba(30, 41, 35, 0.08)`).
  - **Дизайнерская типографика (Literata + Inter):**
    - Заголовки карточек и табов: Literata Medium (24 / 30 px, цвет `#1c2621`).
    - Названия задач и материалов: Inter Regular (16 / 24 px, цвет `#1c2621`).
    - Подписи и метаданные: Inter Regular (13 / 19 px, цвет `#5e6e65`).
    - Кнопки и действия: Inter Medium (14 / 20 px).
    - Текстовые контейнеры не используют снижение `opacity`, сохраняя высокую чёткость и контраст глифов.
  - **Цветовой акцент и иерархия действий:** ровно одна глубокая тёмно-зелёная залитая кнопка (`#233e31`) на весь экран — «Продолжить →». Вторичные действия оформлены спокойными текстовыми ссылками («На сегодня →», «+ Добавить дело на сегодня») и мягкими иконками.
  - **Карточка «Дела» без информационного шума:** в шапке расположены «Сегодня» / «Завтра», иконка календаря `[ 📅 ]` и `+`. Кнопка добавления задачи органично встроена в контент. Просроченные задачи с прошлых дней отображаются в отдельной секции «С прошлых дней» с кнопкой переноса `На сегодня →` в 1 клик, а подвал дополнен плашкой `💭 Мысли без даты · {count}`.
  - **Карточка «Почитать»:** название в 1 слово для исключения переносов, переключатель режимов «список / плитки», квадратные миниатюры с обложками вкладок или Calm-монограммами с фавиконом, градиентная маска переполнения и порционная подгрузка (по 12 шт.) для плавной работы при любом объёме закладок.
  - **Карточка «Почта»:** при отсутствии подключенных аккаунтов выводится чистый заголовок и аккуратная капсула «Подключить Gmail →».
- Шапка рабочих пространств: автоматическое определение контекста для безымянных потоков по открытым вкладкам (`Поток · VK`, `Поток · Figma`), предотвращающее монотонные дубликаты. В полосе табов непрерывно доступны все открытые пространства с горизонтальной прокруткой, а полный каталог пространств доступен по кнопке «Все пространства».
- Новые карточки на дашборде:
  - **«Заметки / Черновик»** — постоянный текстовый блокнот на главном экране с мгновенным автосохранением в SQLite, поддержкой списков задач и кнопкой создания дела из первой строки.
  - **«Почитать»** — полка сохранённых статей и ссылок из пространств с расчетом времени чтения, переключением между списком и плитками с обложками, градиентным растворением переполняющегося контента и отметкой «прочитано».
  - **«Подробная погода»** — детальные метеоусловия (температура, «ощущается как», влажность, ветер, осадки) без внешних платных ключей (Open-Meteo), прогноз на 5–7 дней и удобный селектор городов.
  - **«Карты и пробки»** — интерактивная карточка с поддержкой Яндекс Карт и Google Maps, поиском мест, слоем пробок и быстрым открытием в браузере.
  - **«Забота и привычки»** — спокойный трекер здоровых микро-рутин: интерактивный водный баланс (8 стаканов с процедурным звуком капли), отдых для глаз (правило 20-20-20), интерактивное осознанное дыхание (4-4-4 с визуальным кругом и мягким выдохом), разминка и осанка, а также добавление собственных привычек (счётчик или галочка). Детерминированный переход на новый день без штрафных стрик-таймеров и чувства вины.
- Готовые и пользовательские пресеты дашборда:
  - Аккуратно спрятаны в настройки главной (через кнопку настроек справа или плавающую панель в режиме редактирования), чтобы не загромождать главный экран и сохранять визуальное спокойствие.
  - Встроенные режимы:
    - 🧘 **Спокойный (Фокус)** — без внешнего шума (без новостей и почты), только продолжение дел, дзен-таймер, дела и заметки.
    - ⚡ **Рабочий (Кокпит)** — для насыщенного дня: дела, почта Gmail, пространства проектов, дайджест, продолжение и погода.
    - ☕ **Обзор (Стандартный)** — сбалансированный сетап по умолчанию.
    - 🌤️ **Город и день** — городская среда с подробной погодой, картой/пробками, делами и полкой чтения.
    - 🌱 **Баланс и ритуалы** — сетап для заботы о здоровье: привычки и водный баланс, дзен-фокус, дела и заметки.
  - Возможность сохранения собственных пользовательских пресетов, быстрое применение и удаление в настройках главной, транзакционное сохранение в SQLite.
- **Плавающая панель настройки сетки:**
  - Все круглые кнопки приведены к строго единому диаметру **38px** без визуального перегруза и скачков при раскрытии.
  - **In-place отмена/закрытие:** при клике на кнопку настроек в той же физической точке экрана под курсором появляется крестик закрытия (`X`), позволяя выйти из режима редактирования повторным кликом без движения мыши.
  - При наведении на крестик используется мягкий спокойный шалфейный тон без тревожных красных цветов.
  - Кнопка вызова пресетов вынесена на самый низ панели и аккуратно отделена деликатным разделителем.
- «Настроить главную» позволяет менять размер S/M/L, порядок, набор карточек, выбирать готовые пресеты или сохранять собственные сетапы.

Island показывает один актуальный сигнал: напоминание, выбранное уведомление встречи, фокус или важное письмо. Завершение дела в island можно отменить. Все плашки отмены и восстановления («Пространство удалено», «Дело завершено», «Вкладка закрыта») носят временный характер: они автоматически исчезают через 6 секунд, не загромождая экран, ставятся на паузу при наведении курсора (возобновление с задержкой 3 сек. после ухода мыши), закрываются по клику на крестик («✕») и парят строго над нижней капсулой управления без перекрытия кнопок. Живые подсказки включаются отдельно и выполняют одно короткое движение; CSS учитывает prefers-reduced-motion.

## Пространства и вкладки

У каждого пространства есть материалы, набор вкладок и сохранённое продолжение. «Веб» хранит обычный браузинг отдельно от проектных дел. Вкладки всегда сверху: читаемые названия, закрепление, прокрутка колесом и перетаскивание. При переносе на страницу появляются цели для просмотра рядом, другого пространства и сохранения ссылки в материалы. Закрытие и перенос можно отменить. «Сохранить и вернуться» оставляет точку продолжения и возвращает на главную.

«Вкладки» рядом с Лентой или Ctrl/Cmd + Shift + A открывает «Стол». Без запроса это обзор карточек; при вводе — быстрый список результатов. По умолчанию поиск охватывает все дела текущего пространства, переключатель «Все» расширяет его на остальные пространства и «Веб». Запрос сохраняется при переключении. Стрелки выбирают результат, Enter открывает его с нужным делом, Escape возвращает к странице. Поиск учитывает название, адрес, пространство и дело. «+» или Ctrl/Cmd + T создаёт одну новую вкладку с фокусом в постоянной адресной строке. Enter использует эту вкладку; Escape отменяет ввод, а пустую вкладку можно закрыть. Подробности — в [описании браузинга](docs/browsing-ux.md).

Верхняя панель браузинга содержит пульс дня. По нажатию открывается панель событий, дел и фокуса; изменения дел отражаются в дашборде. Кнопка закладки или Ctrl/Cmd + D сохраняет текущую страницу в общие закладки, существующую/новую группу либо материалы выбранного пространства. Последнее место запоминается, вкладка остаётся открытой. Группы закладок доступны на новой вкладке обычного браузинга. Реализованные связи, ограничения и задачи дальнейшей интеграции описаны в [ТЗ UI браузинга](docs/browser-ui-spec.md).

Импорт принимает список HTTP/HTTPS-адресов, HTML-закладки и JSON с окнами Chrome, закреплением и группами. Вставленный набор показывается до добавления. Страницы загружаются при открытии, а не во время импорта. Отдельный экспортёр лежит в `chrome-export`; его установка и проверка на реальных вкладках пока не выполнены.

В Chrome встроенная страница заменена честным предложением открыть сайт в соседней вкладке. Просмотр чужих сайтов внутри приложения, сохранение введённых форм при переключении и защита страниц от закрытия реализованы в Electron через WebContentsView. Введённые формы сохраняются в живом процессе; после полного перезапуска браузера восстановление их содержимого не обещается. cookies и браузерные профили Chrome в Дом не импортируются.

Поиск Ctrl/Cmd + K находит названия пространств и материалов, адреса вкладок, дела и следующий шаг. Это поиск по метаданным, а не по всему содержимому сайтов и файлов. Файл из результатов сохраняет свой тип; дело открывается для редактирования.

## Встроенный AdBlock и нативные суперсилы

Вместо установки сторонних расширений из Chrome Web Store ключевые возможности встроены напрямую в браузерный движок и интерфейс омнибокса:

- **Встроенный AdBlock и Anti-Cookie:** Блокировка рекламы, трекеров и назойливых cookie-нотификаций на базе `@ghostery/adblocker-electron` с предзагруженными правилами EasyList, EasyPrivacy, Peter Lowe, RU AdList, EasyList Cookie и Annoyances. Правила кэшируются в бинарный файл `adblock-cache.bin` и восстанавливаются при старте быстрее чем за 40 мс.
- **Спокойный интерфейс управления (Calm UX):** В адресной строке расположен спокойный значок щита без кричащих красных бейджей с числом заблокированного. При клике открывается поповер с информацией о хосте, числом скрытых элементов, возможностью отключить блокировку для конкретного сайта в 1 клик и тумблером блокировки cookie-уведомлений.
- **Режим чистого чтения (Reader Mode):** Парсинг статей через `@mozilla/readability`. Кнопка книги `[ 📖 ]` в омнибоксе появляется контекстно, только когда прелоад определяет на странице полноценную статью. В режиме чтения открывается спокойный холст с книжной антиквой Literata, расчетом времени чтения, настройкой размера шрифта и 4 темами (Светлая, Сепия, Бумага, Ночь).
- **Умная тёмная тема для сайтов:** На базе `darkreader` — инвертирует контрастность ярких сайтов без искажения иллюстраций, управляется переключателем в поповере щита.
- **Перевод страниц и AI-выжимка:** При открытии страниц на иностранных языках (`lang !== 'ru'`) в омнибоксе появляется кнопка `[ 🌐 ]`. Переводит текст страницы или предлагает получить краткую выжимку материала через подключённого ассистента.
- **Совместимость с Google Auth и Cloudflare Turnstile:** Устранение бесконечной капчи и блокировок формы входа («Браузер не безопасен»): отключен флаг автоматизации Blink (`disable-blink-features AutomationControlled`), заголовки Client Hints (`Sec-CH-UA`, `Sec-CH-UA-Full-Version-List`) синхронизированы с Google Chrome текущей версии Chromium, очищен `navigator.webdriver` в прелоаде и DOM, а для изолированных сценариев сохранён резервный вход через системный браузер («В браузере»).
- **Координация внешних окон Windows 11 (Win32 FFI):** Прямая интеграция с оконным менеджером Windows через легковесный `koffi` (Win32 API: `user32.dll`, `dwmapi.dll`). В панели материалов кабинета можно привязать любое запущенное окно (графический редактор, IDE, офисный пакет). При парковке кабинета привязанные окна сворачиваются, а при возврате к продолжению — разворачиваются и активируются на экране. Фильтрация фантомных окон Windows 11 через DWM, безопасная передача `hwnd` в IPC и фокус без оранжевого мигания таскбара.

## Календарь, почта и новости

ICS-подписки поддерживают повторения, исключения, VTIMEZONE/IANA, переходы времени и события на весь день. Ошибка обновления не уничтожает сохранённые события. В Chrome источник должен разрешать запрос из браузера; часть внешних календарей и RSS ограничена CORS.

Gmail в Electron использует OAuth Desktop app с PKCE и loopback, только scope gmail.readonly. Подключаются несколько аккаунтов. Начальная синхронизация читает до 100 входящих, затем используется history; локальный кеш ограничен 500 письмами на аккаунт. Сохраняются метаданные и snippet, а не полный текст письма. Можно выделять важных отправителей, открыть оригинал или создать дело из письма. Полный OAuth-проход с настоящим аккаунтом и проверка приложения Google ещё не выполнены. В веб-режиме подключение Gmail недоступно.

RSS и Atom собираются в конечный выпуск до 30 материалов, с историей до 7 выпусков. Новый выпуск собирается при открытии Дома, изменении источников и раз в день, пока Дом открыт; есть ручное обновление. Открытый выпуск не меняется во время чтения. После его закрытия карточка показывает актуальный выпуск. Ошибка источника видна в настройках; прежний выпуск остаётся доступным.

При первом подключении новостей предложены Хабр, Спортс и международная лента Ленты.ру. Можно выбрать интересы, добавить свою тему и назначить тему источнику. Явно отключённые источники не возвращаются автоматически. Изображения берутся из RSS или метаданных страницы статьи; отсутствующие изображения подгружаются отдельно, сохраняя доступность текста. Готовые изображения сохраняются в выпуске и повторно используются при обновлении. Для этих трёх готовых сайтов `dev:web` и Vite preview используют ограниченный локальный прокси; произвольные источники в Chrome требуют CORS. Статическая веб-сборка требует своего серверного прокси для готовых лент и страниц. Electron загружает RSS через существующий сетевой мост. Пересказ с ИИ запускается отдельным действием.

Для локальной проверки RSS в настройках можно указать адрес `http://127.0.0.1:5173/qa/fixtures/feed.xml`. Это явно вымышленная тестовая лента.

## Облачный ИИ

В Electron подготовлены OpenAI Responses, Anthropic Messages и совместимый HTTPS endpoint. Пользователь задаёт собственные ключ и модель, выбирает роль: чат, помощник или ассистент. Основные сценарии работают без ИИ.

Контекст добавляется явно: выбранная страница, материалы, дела, фрагменты писем или выпуск новостей. Перед отправкой видно, какие источники включены, и требуется согласие. Для страницы можно передать выделенный текст либо доступный текст страницы. Чтение файлов ограничено поддерживаемыми текстовыми форматами; PDF, Office и Adobe-файлы пока не извлекаются.

ИИ может предложить три внутренних действия: создать дело, сохранить HTTP/HTTPS-ссылку и оставить следующий шаг существующего пространства. Каждое применяется отдельной кнопкой. Отправка писем, удаление данных и произвольные команды не входят в инструменты. Доверенность текста сайта не заменяет пользовательское разрешение.

Фоновые обзоры включаются отдельно и используют только важные непрочитанные snippets и фрагменты новостей. Настраиваются дневной лимит числа запросов и максимальное число выходных токенов. Это технические ограничения, а не точный денежный бюджет. Журнал хранит статус, источники, результат и сообщённое провайдером использование токенов.

В Chrome подключение ключей и реальные запросы ИИ недоступны. Адаптеры проверены тестовыми потоками; реальные вызовы всех трёх провайдеров ещё требуют проверки с ключами владельца.

## Данные Electron

Состояние находится в `dom.sqlite` внутри app.getPath('userData'). Запись выполняет отдельный работник, изменения применяются транзакционно. SQLite FTS5 индексирует метаданные. Прежний `state.json` мигрируется, а исходник сохраняется как `state.json.before-sqlite`. Повреждённый файл не перезаписывается пустым состоянием.

На запуске создаётся `dom.previous.sqlite`; ручная копия — `dom.manual.sqlite`. Автоматическое восстановление из произвольной копии пока не добавлено.

Ключи API, OAuth-токены и новые секретные iCal-адреса хранятся в `secrets.encrypted.json` через safeStorage. При недоступном шифровании сохранение секрета отклоняется. Резервные копии и исходный JSON, созданные до переноса старых iCal-адресов, могут содержать эти адреса; автоматически старые файлы не удаляются. Локальная база с делами, фрагментами писем и ответами ИИ целиком не шифруется.

Системные уведомления и фоновая синхронизация работают, пока Electron запущен. Закрытие окна оставляет приложение в трее Windows; полное завершение — через меню трея. Глобальная запись: Ctrl + Alt + Space на Windows, Cmd + Option + Space на macOS. Подготовка macOS ещё не проверена на реальном Mac.

## Проверки

```powershell
npm test
npm run test:cabinet-native
npm run build
```

`npm test` запускает Vitest (56 файлов, 391 тест) и проверку SQLite через Electron в режиме Node без окна. `npm run test:cabinet-native` проверяет изоляцию кабинетов, выгрузку памяти и сохранение пользовательского ввода в живом окне Electron. `npm run build` проверяет TypeScript и собирает веб-ресурсы.

Статус — в [плане выполнения](IMPLEMENTATION.md), продуктовые принципы — в [PRODUCT.md](PRODUCT.md). Фон и шрифты локальные; при запуске они не требуют сети.
