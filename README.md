# dombro — браузер и спокойный дашборд

dombro сохраняет контекст работы, помогает выбрать следующее действие и держит материалы по пространствам. Доступен как в веб-режиме, так и в виде настольного приложения на Electron для Windows 11.

## Настольный пилот: Кабинеты в Electron

Согласованный UX кабинетов (пространств без вложенных дел, с сохранением каркаса дашборда и открытием нативного браузера только при явных действиях) подключён к Electron и доступен в виде автономной сборки.

### Запуск готовой Portable-версии для Windows 11
Собрана готовая portable-сборка:
```powershell
.\release\dombro-cabinet-0.1.0-Portable.exe
```
Запуск не требует установки или передачи флагов — приложение автоматически запускается с изолированным профилем `%APPDATA%\dombro-cabinet-pilot` и базой SQLite.

### Запуск из исходного кода
```powershell
# Запуск режима кабинетов в Electron (с изолированным профилем dombro-cabinet-pilot):
npm run dev:cabinet

# Запуск нативных тестов кабинетов:
npm run test:cabinet-native

# Сборка portable-версии:
npm run dist:portable:cabinet
```

Подробный отчёт о реализации и тестировании — в [qa/CABINET-ELECTRON.md](qa/CABINET-ELECTRON.md).

## Запуск в Chrome (веб-версия)

Нужны Node.js 22.12+ и npm. Из папки проекта:

```powershell
npm install
npm run dev:web
```

Открыть [личный режим](http://127.0.0.1:5173/) или [пример дня с кабинетами](http://127.0.0.1:5173/?cabinet=1&demo=1).

## Концепция: пространство как кабинет

Новый UX убирает вложенное «Дело», создаёт пустое пространство без формы имени и показывает материалы рядом с браузером.
Выбор, создание и продолжение пространства в дашборде сохраняют его каркас. Только явное открытие браузера или вкладок раскрывает браузерный режим; возврат ведёт в прежний раздел дашборда.

В выбранном пространстве теперь видны сами вкладки, конкретные документы и отдельные инструменты. Есть поиск, фильтры, меню по правой кнопке и перестановка пространств. Вкладку можно перетащить в другое пространство, а документ — добавить туда же без удаления исходной ссылки. Необязательные миниатюры используют готовые снимки просмотренных страниц из памяти Electron; веб-пилот не загружает сайты ради превью и не сохраняет изображения в БД. Подробности проверки и границы нативного подключения — в [qa/CABINET-DASHBOARD.md](qa/CABINET-DASHBOARD.md). Для уже собранного portable-приложения требуется пересборка.

Полная продуктовая сводка, правила документов и памяти, гипотезы и этапы «браузер → Windows 11 → macOS» находятся в [docs/cabinet-upgrade.md](docs/cabinet-upgrade.md). Описанное ниже прежнее поведение сохраняется в режиме без `cabinet=1`. Локальный ИИ и новая нативная выгрузка памяти в пилот не входят.

Пример дня хранится в sessionStorage отдельно от личных записей. Письма в нём вымышлены и помечены как примеры; новости загружаются из настоящих RSS с изображениями и рубриками. Сохранённый старый пример автоматически подключает источники и убирает вымышленные статьи, сохраняя изменения дел и пространств. «Настройки → Начать заново» сбрасывает только пример. В Chrome личные данные хранятся в IndexedDB; прежний localStorage мигрируется при чтении.

## Главная и ежедневные действия

- Крупная дата открывает календарь. Дела можно смотреть списком, неделей и месяцем.
- Карточка «Продолжить» возвращает к последнему делу: выбранным документам и его группе вкладок. Пространство, название, необязательный следующий шаг и состав видны до открытия. В меню — настройка состава и завершение с отменой.
- В одном пространстве могут быть разные дела. В браузере их выбирают над вкладками; в материалах пространства показано текущее дело для открываемых документов. История содержит до 20 сохранений пространства, заметки и снимки относятся к своему делу.
- Вкладки автоматически сохраняются в текущем деле. Документ присоединяется после успешного открытия из Дома; сохранение файла или ссылки в материалы само по себе не включает их в продолжение. Можно явно выбрать документы в настройке карточки. Сохраняются пути к файлам, а не копии содержимого; сохранением изменений занимается редактор документа.
- Продолжение сохраняет другие группы и не заменяет живые вкладки старым снимком. «Сохранить и вернуться» скрывает страницы без закрытия. При частичной ошибке повторяются только неоткрытые документы; повторное нажатие во время открытия блокируется.
- В Windows документы открываются через системную программу по умолчанию. Автоматическое обнаружение документов, открытых вне Дома, выбор конкретного редактора, активация уже открытого внешнего документа и восстановление несохранённых изменений пока не реализованы. В Chrome локальные файлы не запускаются; группа показывается в веб-прототипе. Подробности — в [описании карточки](docs/resume-card-ux.md).
- День выполнения, срок и время напоминания — отдельные поля. Фраза «завтра проверить макет» создаёт дело на завтра без автоматического таймера.
- «Записать» и «Спросить ИИ» в нижней капсуле открывают поле над ней. Режимы сохраняют отдельные черновики; Escape закрывает поле и возвращает фокус на кнопку. Быстрый ввод сохраняет по Enter. Shift + Enter добавляет строку; многострочный текст можно сохранить через Ctrl/Cmd + Enter. Черновики сохраняются в пределах браузерной сессии.
- Стандартная главная показывает продолжение, план дня и горизонтальную ленту новостей. Главная, пространства и их обзор используют одну высоту дашборда: верхняя панель и нижняя капсула сохраняют положение при переключении табов. На обычной ширине видны три карточки и край четвёртой. В карточке — изображение статьи, заголовок и рубрика; в шапке — табы рубрик. «Главное» начинает ленту свежими материалами из разных интересов. Полоса прокрутки поддерживает перетаскивание и клавиатуру; также работают колесо мыши и свайп. По нажатию открываются фрагмент, ссылка на источник и обсуждение с ИИ.
- «Одно дело» оставляет продолжение, одно дело и быструю запись. Прочие карточки остаются в настройках и возвращаются в режиме обзора.
- «Настроить главную» меняет размер S/M/L, порядок и набор карточек. Можно скрыть карточку, отменить изменение и вернуть стандартную раскладку.

Island показывает один актуальный сигнал: напоминание, выбранное уведомление встречи, фокус или важное письмо. Завершение дела в island можно отменить. Живые подсказки включаются отдельно и выполняют одно короткое движение; CSS учитывает prefers-reduced-motion.

## Пространства и вкладки

У каждого пространства есть материалы, набор вкладок и сохранённое продолжение. «Веб» хранит обычный браузинг отдельно от проектных дел. Вкладки всегда сверху: читаемые названия, закрепление, прокрутка колесом и перетаскивание. При переносе на страницу появляются цели для просмотра рядом, другого пространства и сохранения ссылки в материалы. Закрытие и перенос можно отменить. «Сохранить и вернуться» оставляет точку продолжения и возвращает на главную.

«Вкладки» рядом с Лентой или Ctrl/Cmd + Shift + A открывает «Стол». Без запроса это обзор карточек; при вводе — быстрый список результатов. По умолчанию поиск охватывает все дела текущего пространства, переключатель «Все» расширяет его на остальные пространства и «Веб». Запрос сохраняется при переключении. Стрелки выбирают результат, Enter открывает его с нужным делом, Escape возвращает к странице. Поиск учитывает название, адрес, пространство и дело. «+» или Ctrl/Cmd + T создаёт одну новую вкладку с фокусом в постоянной адресной строке. Enter использует эту вкладку; Escape отменяет ввод, а пустую вкладку можно закрыть. Подробности — в [описании браузинга](docs/browsing-ux.md).

Верхняя панель браузинга содержит пульс дня. По нажатию открывается панель событий, дел и фокуса; изменения дел отражаются в дашборде. Кнопка закладки или Ctrl/Cmd + D сохраняет текущую страницу в общие закладки, существующую/новую группу либо материалы выбранного пространства. Последнее место запоминается, вкладка остаётся открытой. Группы закладок доступны на новой вкладке обычного браузинга. Реализованные связи, ограничения и задачи дальнейшей интеграции описаны в [ТЗ UI браузинга](docs/browser-ui-spec.md).

Импорт принимает список HTTP/HTTPS-адресов, HTML-закладки и JSON с окнами Chrome, закреплением и группами. Вставленный набор показывается до добавления. Страницы загружаются при открытии, а не во время импорта. Отдельный экспортёр лежит в `chrome-export`; его установка и проверка на реальных вкладках пока не выполнены.

В Chrome встроенная страница заменена честным предложением открыть сайт в соседней вкладке. Просмотр чужих сайтов внутри приложения, сохранение введённых форм при переключении и защита страниц от закрытия реализованы в Electron через WebContentsView. Введённые формы сохраняются в живом процессе; после полного перезапуска браузера восстановление их содержимого не обещается. cookies и браузерные профили Chrome в Дом не импортируются.

Поиск Ctrl/Cmd + K находит названия пространств и материалов, адреса вкладок, дела и следующий шаг. Это поиск по метаданным, а не по всему содержимому сайтов и файлов. Файл из результатов сохраняет свой тип; дело открывается для редактирования.

## Календарь, почта и новости

ICS-подписки поддерживают повторения, исключения, VTIMEZONE/IANA, переходы времени и события на весь день. Ошибка обновления не уничтожает сохранённые события. В Chrome источник должен разрешать запрос из браузера; часть внешних календарей и RSS ограничена CORS.

Gmail в Electron использует OAuth Desktop app с PKCE и loopback, только scope gmail.readonly. Подключаются несколько аккаунтов. Начальная синхронизация читает до 100 входящих, затем используется history; локальный кеш ограничен 500 письмами на аккаунт. Сохраняются метаданные и snippet, а не полный текст письма. Можно выделять важных отправителей, открыть оригинал или создать дело из письма. Полный OAuth-проход с настоящим аккаунтом и проверка приложения Google ещё не выполнены. В веб-режиме подключение Gmail недоступно.

RSS и Atom собираются в конечный выпуск до 30 материалов, с историей до 7 выпусков. Новый выпуск собирается при открытии Дома, изменении источников и раз в день, пока Дом открыт; есть ручное обновление. Открытый выпуск не меняется во время чтения. После его закрытия карточка показывает актуальный выпуск. Ошибка источника видна в настройках; прежний выпуск остаётся доступным.

При первом подключении новостей предложены Хабр, Спортс и международная лента Ленты.ру. Можно выбрать интересы, добавить свою тему и назначить тему источнику. Явно отключённые источники не возвращаются автоматически. Изображения берутся из RSS или метаданных страницы статьи; отсутствующие изображения подгружаются отдельно, сохраняя доступность текста. Готовые изображения сохраняются в выпуске и повторно используются при обновлении. Для этих трёх готовых сайтов `dev:web` и Vite preview используют ограниченный локальный прокси; произвольные источники в Chrome требуют CORS. Статическая веб-сборка требует своего серверного прокси для готовых лент и страниц. Electron загружает RSS через существующий сетевой мост. Пересказ с ИИ запускается отдельным действием.

Для локальной проверки RSS в настройках можно указать адрес `http://127.0.0.1:5173/qa/fixtures/feed.xml`. Это явно вымышленная тестовая лента.

## Облачный ИИ

В Electron подготовлены OpenAI Responses, Anthropic Messages и совместимый HTTPS endpoint. Пользователь задаёт собственные ключ и модель, выбирает роль: чат, помощник или ассистент. Основные сценарии работают без ИИ.

Контекст добавляется явно: выбранная страница, материалы, дела, фрагменты писем или выпуск новостей. Перед отправкой видно, какие источники включены, и требуется согласие. Для страницы можно передать выделенный текст либо доступный текст страницы. Чтение файлов ограничено поддерживаемыми текстовыми форматами; PDF, Office и Adobe-файлы пока не извлекаются.

ИИ может предложить три внутренних действия: создать дело, сохранить HTTP/HTTPS-ссылку и оставить следующий шаг существующего пространства. Каждое применяется отдельной кнопкой. Отправка писем, удаление данных и произвольные команды не входят в инструменты. Доверенность текста сайта не заменяет пользовательское разрешение.

Фоновые обзоры включаются отдельно и используют только важные непрочитанные snippets и фрагменты новостей. Настраиваются дневной лимит числа запросов и максимальное число выходных токенов. Это технические ограничения, а не точный денежный бюджет. Журнал хранит статус, источники, результат и сообщённое провайдером использование токенов.

В Chrome подключение ключей и реальные запросы ИИ недоступны. Адаптеры проверены тестовыми потоками; реальные вызовы всех трёх провайдеров ещё требуют проверки с ключами владельца.

## Данные Electron

Состояние находится в `dom.sqlite` внутри app.getPath('userData'). Запись выполняет отдельный работник, изменения применяются транзакционно. SQLite FTS5 индексирует метаданные. Прежний `state.json` мигрируется, а исходник сохраняется как `state.json.before-sqlite`. Повреждённый файл не перезаписывается пустым состоянием.

На запуске создаётся `dom.previous.sqlite`; ручная копия — `dom.manual.sqlite`. Автоматическое восстановление из произвольной копии пока не добавлено.

Ключи API, OAuth-токены и новые секретные iCal-адреса хранятся в `secrets.encrypted.json` через safeStorage. При недоступном шифровании сохранение секрета отклоняется. Резервные копии и исходный JSON, созданные до переноса старых iCal-адресов, могут содержать эти адреса; автоматически старые файлы не удаляются. Локальная база с делами, фрагментами писем и ответами ИИ целиком не шифруется.

Системные уведомления и фоновая синхронизация работают, пока Electron запущен. Закрытие окна оставляет приложение в трее Windows; полное завершение — через меню трея. Глобальная запись: Ctrl + Alt + Space на Windows, Cmd + Option + Space на macOS. Подготовка macOS ещё не проверена на реальном Mac.

## Проверки

```powershell
npm test
npm run build
```

`npm test` запускает Vitest и проверку SQLite через Electron в режиме Node без окна. `npm run build` проверяет TypeScript и собирает веб-ресурсы; Windows-приложение эта команда не упаковывает.

Нативная проверка браузера — `npm run test:browser`; она запускает скрытый Electron и сейчас отделена от текущей приёмки в Chrome. Упаковочные команды сохранены в package.json, но актуальный Windows-дистрибутив не создаётся до возвращения к этому этапу.

Статус — в [плане выполнения](IMPLEMENTATION.md), протокол Chrome — в [qa/CHROME.md](qa/CHROME.md), продуктовые принципы — в [PRODUCT.md](PRODUCT.md). Фон и шрифты локальные; при запуске они не требуют сети.
